# FastPay Web

Marketing landing site for FastPay — follows the Finto fintech layout with the FastPay palette:

| Role | Color |
|------|-------|
| Aqua (accents, CTAs) | `#00AEEF` |
| Navy (dark sections) | `#0B1F3F` |
| Dark blue (depth, top bar, footer) | `#08182F` |

## Quick start

```bash
cd fastpay-web
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview  # preview production build
```

## Sections

- Top bar + sticky nav
- Hero with grid background + social proof
- 3 feature cards (cards, transfers, insights)
- Analytics deep-dive with **weekly / monthly / yearly** budget toggle
- Logo strip, services grid, testimonials
- Pricing (3 tiers), FAQ accordion, footer + newsletter

## Stack

Vite + React + TypeScript, plain CSS (no UI framework).
